✨ About Mishi

Mishi provides a range of Discord server features, including:

- 🎵 Music playback and audio controls.
- 🛡️ Automated moderation and spam protection.
- 🔗 Discord invite and link filtering.
- ⚠️ Configurable moderation punishments.
- ⏱️ Member timeout management.
- 📋 Dedicated moderation action logs.
- ⚙️ Server configuration and utility commands.

🔐 Privacy and Data

Mishi processes information only as needed to provide its features.

Depending on enabled functionality, this may include Discord user IDs, server IDs, channel IDs, message content, command inputs, and moderation records.

Message content may be inspected for prefix commands and AutoMod. Detected violations may be recorded in the server's designated moderation logging channel.

For complete information, please read our "Privacy Policy" (PRIVACY_POLICY.md).
